# 📞 Call Center Performance Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Call Center Performance Dashboard** designed to analyze call volume, agent performance, call resolution, rejection rates, call duration, customer satisfaction, topics, and monthly trends. The dashboard provides a centralized view of call center operations and helps identify high-performing agents, monitor service efficiency, and understand call patterns across different months and topics.

---

## 🎯 Objectives

The main objective of this project is to analyze call center performance and evaluate the efficiency of customer support operations. The dashboard aims to track total calls, answered and rejected calls, compare agent performance, analyze call resolution and duration, monitor customer satisfaction, identify popular call topics, and evaluate monthly call trends to generate actionable insights for improving customer service and operational efficiency.
